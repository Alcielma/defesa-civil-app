### ⚙️ Backend — API

Tecnologias responsáveis pelo processamento das requisições, autenticação e persistência dos dados no servidor.

  PHP • Laravel • SQLite
</p>

- **PHP:** linguagem utilizada no desenvolvimento da API.
- **Laravel:** framework responsável pelas rotas, regras de negócio e operações da API.
- **Laravel Sanctum:** autenticação por tokens para acesso protegido.
- **SQLite:** banco de dados utilizado na configuração atual do backend.

### 🏗️ Arquitetura

**Clean Architecture** — organização em camadas para separar as regras de negócio, o acesso aos dados e a interface, facilitando a manutenção e a evolução do sistema.
